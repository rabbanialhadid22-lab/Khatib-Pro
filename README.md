# Khatib Pro — Jadwal Khutbah Jumat

Aplikasi web (PWA) untuk mencatat jadwal khutbah Jumat tahun ini dan tahun-tahun berikutnya: semua hari Jumat sudah tersedia, pilih tahunnya di bagian atas, tinggal diisi masjid, alamat, judul, kontak, dan tautan peta.

Fitur: status Terlaksana / Tidak terlaksana (dengan alasan), rekap tahunan, filter per bulan dan status, pengingat H-7 dan H-1, ekspor kalender (.ics), cadangan data.

## Pasang lewat GitHub Pages
1. Buat repositori baru di github.com (nama bebas, misalnya `khutbah-2027`, pilih Public).
2. Unggah semua isi folder ini (semua file (`index.html`, `sw.js`, `manifest.webmanifest`, dan 4 file `.png`)) ke repositori.
3. Buka Settings > Pages > Source: Deploy from a branch > Branch: `main`, folder `/ (root)` > Save.
4. Tunggu 1-2 menit. Alamatnya: `https://NAMA-GITHUB-ANDA.github.io/khutbah-2027/`

## Pasang di HP Android
Buka alamat di Chrome > menu titik tiga > Instal aplikasi (atau Tambahkan ke layar utama).
Lalu buka Pengaturan di aplikasi > atur jam pengingat > Aktifkan notifikasi.

## Catatan
- Data tersimpan di browser perangkat, bukan di GitHub. Repositori hanya berisi kode aplikasi.
- Buat cadangan lewat Pengaturan > Simpan cadangan.
